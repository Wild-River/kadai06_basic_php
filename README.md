# ①課題名

旅費の記録

## ②課題内容（どんな作品か）

- 旅行ごとの支出を記録し、合計金額や支出内訳をグラフで確認できるアプリです。
- 登録画面では、旅行名・支出日・カテゴリ・金額・メモを入力して支出を記録できます。
- 一覧画面では、カテゴリ別の支出をドーナツグラフ、旅行ごとの合計金額を棒グラフで可視化しています。

## ③アプリのデプロイURL

- https://gs2026-arakawa.sakura.ne.jp//kadai06_basic_php/

## ④アプリのログイン用IDまたはPassword（ある場合）

- ログインなし（登録フォームから入力して登録するだけで利用できます）

## ⑤工夫した点・こだわった点

- まずはPHPによる「登録（Create）」と「表示（Read）」を自分の手で実装することを目標にしました。授業で学んだ `file_put_contents()` と `file_get_contents()` を利用し、JSONファイルへの保存と読み込みを行っています。
- PHPで集計したデータを `json_encode()` を用いてJavaScriptへ受け渡し、ApexChartsでグラフを描画しています。カテゴリ別・旅行別の集計はPHP側で行い、その結果をドーナツグラフと棒グラフに反映しました。
- ユーザー入力を画面へ出力する箇所では、すべて `htmlspecialchars()`（func.phpで定義した共通関数 `h()`）を通し、XSS対策を行いました。
- 旅行名の入力欄には `<datalist>` を動的に生成し、過去に登録した旅行名を候補として表示しています。同じ旅行の支出を追加登録する際の入力負担を減らせるよう工夫しました。

## ⑥難しかった点・次回トライしたいこと（又は機能）

- ApexChartsを利用したグラフ表示の実装に苦戦しました。
- 次回は更新・削除機能を追加し、CRUD（Create / Read / Update / Delete）を完成させたいと考えています。
- また、現在のファイルベースの保存方式からデータベースへ移行し、旅行単位での集計や検索など、より実践的な機能を実装したいです。
